# Sicherheit

Sicherheitslücken bitte **nicht** als öffentliches Issue melden, sondern vertraulich über [Sicherheitslücke melden](https://github.com/streckenwacht/integration/security/advisories/new) (Reiter *Security* → *Report a vulnerability*). Ich melde mich so bald wie möglich.

Unterstützt wird jeweils die neueste Version.

*English:* Please report security issues privately via [Report a vulnerability](https://github.com/streckenwacht/integration/security/advisories/new), not as a public issue. Only the latest release is supported.
